    Domain generalization (DG) studies the problem of training a visual recognition
    model on a set of source domains and deploying it on unseen target domains
    without access to target-domain data during training.
    %
    This report presents our course project on \method{}, a multiscale and
    multilayer contrastive learning framework for visual domain generalization.
    %

    feature maps through multiple parallel concentration pipelines at several spatial

\section{Introduction}

Modern image classifiers achieve strong in-distribution performance, but their
accuracy drops sharply when test images come from a visual context absent during
training.  This is common in practice: a model trained on photographs may fail on
sketches, artworks, cartoons, or images captured under different lighting or camera
conditions.  The root cause is that empirical risk minimization (ERM) does not
distinguish between \emph{class-causal evidence} and \emph{domain-specific
shortcuts}.  If a training domain repeatedly associates a class with a background,
texture, or color distribution, a high-capacity CNN can exploit that correlation
while still achieving low source-domain error.

Domain generalization addresses this failure mode under a strict constraint:
target-domain images and labels are unavailable during training.  A DG model must
therefore learn representations that remain useful under distribution shift by
relying only on the diversity present in source domains.

Our project studies a multiscale and multilayer contrastive learning framework
for domain generalization~\cite{ballas2024m2cl}.  The central idea is that
intermediate CNN features contain rich class-discriminative information that can
be lost or entangled with domain-specific attributes in the final feature vector.
The model therefore extracts representations from multiple layers and multiple
spatial scales, then regularizes them with a supervised contrastive objective that
promotes class-level invariance across source domains.

\section{Problem Formulation}

Let $\mathcal{D} = \{D_1, D_2, \ldots, D_N\}$ be a set of source domains.
Each domain contains image-label pairs $(x,y)$ drawn from a domain-specific joint
distribution over $\mathcal{X} \times \mathcal{Y}$.  Under the
leave-one-domain-out protocol, one domain is held out as the unseen target domain
while the remaining domains form the training and validation set.  The goal is to
learn a classifier $f_\theta: \mathcal{X} \rightarrow \mathcal{Y}$ that minimizes
target-domain error without ever observing target-domain data during training.

The central challenge is \emph{representation entanglement}.  A learned feature
vector may capture both class-specific attributes (object shape, discriminative
parts) and domain-specific attributes (sketch strokes, cartoon colors, background
scenes, lighting, or image texture).  If the classifier relies on the latter, it
will fail when the target domain shifts.  The desired behavior is to produce
features that preserve class information while suppressing unstable
domain-specific correlations.

\section{Related Work}

Several families of methods have been proposed for DG, as summarized in
Table~\ref{tab:method_families}.  ERM is the simplest baseline and trains by
minimizing cross-entropy over pooled source-domain data.  Regularization methods
such as RSC suppress dominant features to prevent shortcut reliance.  Distribution
alignment methods such as CORAL and MMD encourage source-domain feature
distributions to become closer.  Data-mixing methods such as Mixup construct
interpolated training samples.  Style-oriented methods such as SagNet reduce
dependence on domain-specific style.

\method{} differs from these approaches by explicitly reusing intermediate
convolutional features and regularizing them with a supervised contrastive
objective.  This design is motivated by the insight that early and middle CNN
layers still contain spatial and local visual evidence that may be lost or
entangled by the final global representation.

\section{Proposed Method}

\subsection{Backbone Architecture}

The method uses ImageNet-pretrained ResNet-18 and ResNet-50 backbones.  A
standard ResNet classifier passes the final convolutional output through global
average pooling and a linear classifier.  In contrast, \base{} attaches
\emph{extraction blocks} to selected intermediate layers.  These blocks collect
feature maps at several depths, compress them, process them at multiple spatial
scales, and concatenate the resulting vectors into a hypercolumn-like
representation that is then classified by a single fully-connected head.

\subsection{Extraction Block and Concentration Pipelines}

An extraction block receives an intermediate feature map
$F^{(l)} \in \mathbb{R}^{C_l \times H_l \times W_l}$ from layer $l$.  It consists
of a set of parallel \emph{concentration pipelines}, each of which applies the
following sequence of operations:

\begin{enumerate}[leftmargin=1.6em]
  \item A $1{\times}1$ convolution that reduces the channel count by a reduction
        factor $r$, producing $\lfloor C_l / r \rfloor$ channels.
  \item A \codepath{Dropout2d} (spatial dropout) layer that drops entire feature
        maps rather than individual pixels.
  \item A $k{\times}k$ max-pooling layer with stride 1.  The pool size $k$ is
        pipeline-specific: for early layers, the three pipelines use $k \in \{8,
        4, 2\}$; for layers in the last residual block, two pipelines use $k \in
        \{7, 3\}$.
  \item ReLU activation and flattening of the spatial grid.
  \item A two-layer MLP that projects the flattened vector into a compact
        representation of fixed dimension.
\end{enumerate}

Our implementation uses \textbf{3 concentration pipelines per extraction block in
early layers} and \textbf{2 pipelines per block in later layers}, for both
ResNet-18 and ResNet-50.  The outputs of all pipelines from all extraction blocks are
concatenated into a single feature vector, which is passed through a classification
head.

Spatial dropout is crucial here because neighboring pixels in convolutional feature
maps are highly correlated: standard dropout can remove isolated activations while
leaving nearby evidence intact, which is insufficient to regularize shortcut
patterns that span a spatial region.  Dropping entire channels forces the model to
learn predictions that do not rely on any single feature map.

\subsection{Contrastive Regularization}
\label{sec:contrastive_loss}

The full \method{} model adds a supervised contrastive regularizer to the \base{}
architecture.  Let $\bm{u}_i^{(l)}$ be the L2-normalized representation of sample
$i$ extracted from layer $l$, with $\|\bm{u}_i^{(l)}\|=1$.  For a mini-batch of
$N_b$ samples, let $\mathcal{I}_c=\{i \mid y_i=c\}$ be the set of batch indices
belonging to class $c$, and let $N_c=|\mathcal{I}_c|$.

For each layer $l$, the project defines a class-conditional probability measure:
\begin{equation}
  p^{(l)}(c)
  \;=\;
  \frac{%
    \displaystyle
    \sum_{\substack{i,j \in \mathcal{I}_c \\ i<j}}
    e^{\,{\bm{u}_i^{(l)}}^\top \bm{u}_j^{(l)}/\tau}
  }{%
    \displaystyle
    \sum_{1 \le k < m \le N_b}
    e^{\,{\bm{u}_k^{(l)}}^\top \bm{u}_m^{(l)}/\tau}
  },
  \label{eq:p_layer}
\end{equation}
where $\tau>0$ is the temperature hyperparameter.  The numerator sums
cosine-similarity exponentials over all \emph{same-class} pairs, while the
denominator sums over \emph{all} pairs in the batch regardless of label.  Note
that the denominator is the same for all classes and needs to be computed only once
per batch.

The joint probability over all $C$ classes is:
\begin{equation}
  \Pcal^{(l)} \;=\; \prod_{c=1}^{C} p^{(l)}(c),
  \label{eq:P_joint}
\end{equation}
and the layer-wise contrastive loss is:
\begin{equation}
  \Lcal^{(l)}
  \;=\;
  -\log \Pcal^{(l)}
  \;=\;
  -\sum_{c=1}^{C} \log p^{(l)}(c).
  \label{eq:L_layer}
\end{equation}
Minimizing $\Lcal^{(l)}$ pushes same-class pair similarities higher while keeping
cross-class similarities lower relative to the full-batch denominator.  The total
training objective is:
\begin{equation}
  \Lcal
  \;=\;
  \Lcal_{\mathrm{CE}}
  \;+\;
  \alpha \sum_{l=1}^{M} \Lcal^{(l)},
  \label{eq:total_loss}
\end{equation}
where $\Lcal_{\mathrm{CE}}$ is cross-entropy, $M$ is the number of layers from
which representations are extracted, and $\alpha$ controls the contrastive weight.
The default settings are $\alpha=0.01$ and $\tau=1.0$.

\noindent\textbf{Key distinction from SupCon.}  Unlike the standard supervised
contrastive loss (SupCon), which is defined per-anchor and normalizes over all
negatives, this objective defines a \emph{class-level probability} whose
denominator is a batch-level constant.  This makes the loss decomposable by class
and computationally efficient: the denominator need only be computed once per
layer per batch.

\subsection{Model Construction}

The local implementation defines three model families.
\codepath{ERMResNet} keeps the standard ResNet classifier and returns logits with
an empty feature list.
\codepath{OfficialM2} removes the final ResNet fully-connected layer, registers
forward hooks at selected intermediate layers, passes the captured activations
through extraction blocks, concatenates the projected outputs, and classifies the
resulting hypercolumn-like vector.
\codepath{M2CL} is a backward-compatible name for the same architecture with
intermediate energy activations returned for the contrastive loss.

For ResNet-18, extraction blocks are attached to all 13 convolutional and
residual outputs across \codepath{layer1} through \codepath{layer4}.  For
ResNet-50, extraction blocks are connected to the last convolutional layer of
each bottleneck block.

Forward hooks are used to collect intermediate tensors without manually rewriting
the ResNet forward pass.  The tradeoff is that the feature dictionary must be
cleared before each forward pass, and hooks must be removed if the model is
discarded.

\subsection{Extraction Block Details}

The extraction block supports two modes: parallel and cascading.  In the
\emph{parallel} mode, each concentration pipeline has its own $1{\times}1$
convolution before pooling.  In the \emph{cascading} mode, all pipelines share a
single compressed feature map.  The project uses the parallel configuration
because the ablation study (Section~\ref{sec:ablation}) shows stronger overall
performance.

\subsection{Loss Implementation}
\label{sec:loss_impl}

The loss module in \codepath{losses/contrastive.py} computes cross-entropy on the
final logits.  For \base{}, the contrastive weight $\alpha$ is effectively zero.
For \method{}, the module computes the layer score $S_l$ as the log-sum of
same-class pairwise exponentiated cosine similarities, normalized by the total
batch pairwise sum—directly corresponding to $-\Lcal^{(l)}$ from
Eq.~(\ref{eq:L_layer}).  The combined loss is therefore:
\begin{equation}
  \Lcal_{\mathrm{impl}}
  \;=\;
  \Lcal_{\mathrm{CE}} - \alpha \sum_l S_l
  \;=\;
  \Lcal_{\mathrm{CE}} + \alpha \sum_l \Lcal^{(l)},
\end{equation}
which is equivalent to Eq.~(\ref{eq:total_loss}).  The subtraction sign
appears because $S_l$ is a \emph{score} (higher is better), while $\Lcal^{(l)}$
is a \emph{loss} (lower is better), and $S_l = -\Lcal^{(l)}$.

This implementation has a direct practical implication: the quality of the
contrastive signal depends on the batch containing enough same-class pairs.  With
small batches or datasets with many classes, some classes may appear only once in
a batch, contributing no positive-pair signal.  This is one reason the default
batch size is 128.

\subsection{Training Pipeline}

The training entry point loads dataset defaults from configuration files, then
resolves command-line overrides.  \codepath{build\_datasets} constructs a
leave-one-domain-out split: the chosen test domain becomes the unseen target, and
the remaining domains become source environments.

A DomainBed-style source validation split is applied: each source environment is
split with a 0.2 holdout fraction using a seeded hash.  Model selection uses
source validation accuracy rather than target-domain test accuracy, which would
violate the DG protocol.

During training, \codepath{M2Algorithm.update} concatenates mini-batches across
source environments, runs the model, computes the combined objective, and updates
the optimizer.  After training, the best checkpoint is reloaded and evaluated on
the held-out target domain; metrics are saved as JSON files for later aggregation.

\subsection{Configuration Defaults}

Project defaults for \base{} and \method{}: ImageNet-pretrained ResNet-18 or
ResNet-50, SGD optimizer, learning rate $0.001$, 30 epochs, batch size 128,
reduction ratio $r=4$, dropout probability 0.3, $\alpha=0.01$, $\tau=1.0$.
Baseline methods use separate DomainBed-style defaults because they have
different optimization behavior.

\section{Ablation and Sensitivity Analysis}
\label{sec:ablation}

The ablation study isolates four design choices: extraction pipeline type
(cascading vs.\ parallel), reduction factor $r$, spatial dropout, and the
contrastive loss.  All runs use ResNet-18 on PACS and VLCS.

The best configuration in the project is: parallel pipeline, $r=4$, spatial
dropout enabled, and contrastive loss active.  Adding the contrastive loss to this
configuration improves PACS from 79.15 to 80.10 and VLCS from 73.14 to 74.15
in the ablation setting.

\begin{table}[H]
\centering
\caption{Interpretation of the ablation and sensitivity study.}
\label{tab:ablation_interpretation}
\small
\begin{adjustbox}{max width=\textwidth}
\begin{tabular}{llll}
\toprule
\rowcolor{headerblue}
Design choice       & Tested variants    & Best setting          & Interpretation \\
\midrule
Pipeline layout     & cascading, parallel & parallel             & Separate scale-specific pipelines preserve richer evidence. \\
Reduction ratio $r$ & 2, 4, 6            & 4                    & Balances compactness and information retention. \\
Spatial dropout     & with / without     & with dropout         & Drops correlated feature maps, reducing shortcut dependence. \\
Loss weight $\alpha$ & $0$ to $10^{-1}$ & small nonzero value  & Helpful as regularizer; harmful when it dominates CE. \\
Temperature $\tau$  & 0.01 to 100        & near 1.0 (default)   & Controls sharpness of pair-similarity distribution. \\
\bottomrule
\end{tabular}
\end{adjustbox}
\end{table}

\subsection{Key Lessons from the Ablation}

\textbf{Parallel vs.\ cascading pipelines.}  Cascading pipelines share the same
compressed feature map across all scales, saving parameters but limiting
flexibility.  Parallel pipelines allow each scale to learn its own compression,
which yields better performance on average.

\textbf{Reduction ratio.}  A small $r$ preserves more information but passes more
domain-specific detail to the classifier.  A large $r$ reduces memory but may
discard useful class evidence.  $r=4$ is a stable compromise.

\textbf{Spatial dropout.}  In convolutional maps, adjacent activations are
correlated.  Standard dropout can leave enough neighboring information for
shortcuts to survive.  Dropping entire channels forces the model to rely on diverse
evidence rather than narrow local patterns.

\textbf{Contrastive loss.}  The sensitivity analysis shows that $\alpha$ must be
small.  When $\alpha=10^{-1}$, the contrastive objective dominates cross-entropy
and accuracy degrades by more than 15 percentage points on PACS.  The contrastive
term should regularize the classifier, not replace the supervised objective.

\section{Discussion}

\subsection{What the Results Support}

The project results support three main conclusions.  First, using intermediate
representations is beneficial: combining features from multiple semantic depths
gives the classifier access to both local (texture, edge) and global (object,
shape) evidence.  Second, spatial dropout regularizes whole feature maps rather
than isolated pixels, making the extraction block less dependent on narrow local
patterns.  Third, the contrastive loss improves class-level compactness by pulling
same-class representations together and pushing different classes apart.  However,
the sensitivity analysis shows that the contrastive weight must be kept small.

\subsection{Implementation Takeaways}

The project turns the method into an executable training and evaluation pipeline.
The most important engineering decisions are the use of forward hooks for
intermediate activations, extraction blocks sized for different ResNet stages, a
common interface for baselines, and JSON/CSV outputs for result aggregation.  This
structure makes it possible to run the same leave-one-domain-out protocol across
PACS, VLCS, and Office-Home while keeping the model-specific code isolated.

\subsection{Practical Engineering Observations}

Implementing \method{} is significantly more involved than ERM.  ERM requires only
a backbone, a classifier, and cross-entropy.  \method{} requires forward hooks for
intermediate activations, extraction blocks sized for different layer shapes,
concatenation of many projected vectors, and a layer-wise pair objective.

The forward-hook design creates hidden state: the feature dictionary must be
cleared at the start of each forward pass.  Memory is also a concern: extraction
blocks create additional tensors before and after pooling, and the contrastive loss
computes batch-level pairwise similarities.  Larger backbones and larger batches
increase GPU memory demand substantially.

\subsection{Threats to Validity}

Three main threats limit the strength of quantitative conclusions.  First,
incomplete or single-seed runs limit statistical confidence.  Second, DG
performance can vary significantly across random seeds and data augmentation
choices.  Third, implementation details such as augmentation type, optimizer
settings, and source validation splits can influence the final numbers even when
the high-level protocol is unchanged.

%% ═══════════════════════════════════════════════════════════════════════════
\section{Limitations}

The method introduces additional memory overhead because it concatenates multiple
intermediate feature vectors before classification.  This is especially relevant
for ResNet-50 and large batch sizes.  The contrastive component also depends on
batch composition: if a batch contains too few positive pairs per class (as in
Office-Home with 65 classes), the contrastive signal becomes weaker.  Future work
could address these issues with gradient checkpointing for memory and
hard-negative mining for more informative batches.

\section{Conclusion}

This report presented a detailed project study of \method{} for domain
generalization.  The method addresses shortcut learning by extracting multiscale
representations from intermediate CNN layers and by applying a supervised
contrastive loss—defined as a class-conditional probability over pairwise
similarities (Eq.~\ref{eq:p_layer}--\ref{eq:total_loss})—to improve class-level
alignment across source domains.

On PACS, VLCS, and Office-Home, the project results show that \method{}
consistently improves average accuracy over strong DG baselines under both
ResNet-18 and ResNet-50 backbones.
Qualitative saliency maps further support the hypothesis that the method focuses
more on object-relevant regions and less on unstable context.
